# Advanced Binary Search

Binary search in a sorted array of integers that returns the index of the
**first** occurrence of a value, using recursion.

## Files

- `search_algos.h` - header file (prototypes)
- `0-advanced_binary.c` - `int advanced_binary(int *array, size_t size, int value);`

## Compilation

```
gcc -Wall -Wextra -Werror -pedantic 0-main.c 0-advanced_binary.c -o 0-advanced_binary
```
